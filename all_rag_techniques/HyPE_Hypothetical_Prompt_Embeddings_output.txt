🎯 LEZIONI CHIAVE:
   1. HyPE trasforma il retrieval in matching domanda-domanda
      → Elimina il mismatch di stile query-documento
   2. Le domande ipotetiche sono generate OFFLINE durante l'indicizzazione
      → Zero overhead a runtime, retrieval veloce come RAG standard
   3. Ogni chunk ha rappresentazioni multiple (multi-vector)
      → Maggiore flessibilità e copertura semantica
   4. Combinabile con altre tecniche RAG avanzate
      → Reranking, query expansion, hybrid search

💡 QUANDO USARE HyPE:
   ✅ Query degli utenti variano molto nello stile
   ✅ Documenti tecnici con terminologia specifica
   ✅ Necessità di alta precisione nel retrieval
   ✅ Possibilità di indicizzazione offline

⚠️  QUANDO HyPE HA MENO IMPATTO:
   - Query e documenti già ben allineati nello stile
   - Documenti molto brevi o semplici
   - Necessità di aggiornamenti frequenti (costoso rigenerare domande)
